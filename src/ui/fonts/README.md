# Bundled fonts

- `Literata.ttf` is from the Google Fonts Literata family: https://github.com/google/fonts/tree/main/ofl/literata
- `SourceSerif4.ttf` is from Source Serif 4: https://github.com/google/fonts/tree/main/ofl/sourceserif4
- `AtkinsonHyperlegible-*.ttf` is from Atkinson Hyperlegible: https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible
- Each family is licensed under the SIL Open Font License 1.1; corresponding license texts are included in this directory.
